3. Flujo de una petición típica

Secuencia simplificada de un caso de uso: un Administrador da de alta un Inquilino desde la web. 

sequenceDiagram
    autonumber
    actor Admin as Administrador
    participant V as Vista Razor
(Inquilinos/Form)
    participant MC as MVC
InquilinosController
    participant AC as ApiClient
(HttpClient)
    participant MW as Middleware
(JWT + Sesion)
    participant AP as API
InquilinosController
    participant SV as Service
InquilinoService
    participant RP as Repository
InquilinoRepository
    participant DB as SQL Server
(Inquilino)

    Admin->>V: Llena formulario y envía
    V->>MC: POST /Inquilinos/Create
    MC->>AC: PostAsync("inquilinos", dto, JWT)
    AC->>MW: HTTP POST + Bearer
    MW->>MW: Valida JWT y Sesion.Activa
    MW->>AP: Request autenticada
    AP->>SV: CreateAsync(dto)
    SV->>SV: Validaciones de negocio
    SV->>RP: AddAsync(entidad)
    RP->>DB: INSERT Inquilino
    DB-->>RP: Id generado
    RP-->>SV: Entidad
    SV-->>AP: DTO
    AP-->>AC: 201 Created
    AC-->>MC: InquilinoDto
    MC-->>V: Redirect a Index
    V-->>Admin: Lista actualizada
